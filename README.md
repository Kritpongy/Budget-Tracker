# Budget-Tracker
โครงการนี้เป็นโปรแกรมภาษา Python ที่พัฒนาขึ้นเพื่อช่วยแก้ปัญหาการติดตามรายรับ-รายจ่ายในชีวิตประจำวัน โดยตัวโปรแกรมจะช่วยบันทึกข้อมูลการใช้จ่าย เก็บรักษาประวัติข้อมูลอย่างเป็นระบบ และคำนวณสรุปยอดการใช้จ่ายทั้งแบบรายสัปดาห์และรายเดือน ในดิสคอร์ดซึ่งเป็นแอปที่ผมคิดว่าคนหมู่มากใช้จึงสร้างสิ่งนี้ขึ้นมา
