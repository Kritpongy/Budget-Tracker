# Budget-Tracker

โครงการนี้เป็นโปรแกรมภาษา Python ที่พัฒนาขึ้นเพื่อช่วยแก้ปัญหาการติดตามรายรับ-รายจ่ายในชีวิตประจำวัน โดยโปรแกรมจะช่วยบันทึกข้อมูลการใช้จ่าย เก็บรักษาประวัติข้อมูลอย่างเป็นระบบ และคำนวณสรุปยอดการใช้จ่ายทั้งแบบรายสัปดาห์และรายเดือนผ่าน Discord ซึ่งเป็นแอปพลิเคชันที่ผู้คนจำนวนมากใช้งาน จึงเป็นที่มาของการพัฒนาโครงการนี้ขึ้นมา โดยแนวคิดในการพัฒนาได้รับแรงบันดาลใจจากวิดีโอเกี่ยวกับการสร้าง Discord Bot และนำมาต่อยอดให้เหมาะสมกับรูปแบบและฟังก์ชันการทำงานของโครงการ

## แหล่งที่มาของแรงบันดาลใจ

[ดูวิดีโอที่เป็นแรงบันดาลใจในการพัฒนา](https://www.youtube.com/watch?v=2k9x0s3awss&t=952s)

## วิธีใช้งาน

1. ตั้งค่า Token ของ Discord Bot ผ่านตัวแปร `DISCORD_TOKEN` ตามวิธีที่กำหนดไว้ในไฟล์ `bot.py`
2. กำหนด `CHANNEL_ID` ให้ตรงกับ ID ของช่อง Discord ที่ต้องการใช้งาน หากโปรแกรมมีการใช้ตัวแปรนี้

## คำสั่งของบอท

- `!spend 50 Lunch | Food` — บันทึกรายจ่ายพร้อมระบุหมวดหมู่
- `!week` — สรุปรายจ่ายในช่วง 7 วันที่ผ่านมา
- `!month` — สรุปรายจ่ายของเดือนนี้
- `!categories` — สรุปรายจ่ายแยกตามหมวดหมู่
- `!recent 5` — แสดงรายการรายจ่ายล่าสุด 5 รายการ
