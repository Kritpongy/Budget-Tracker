# Budget-Tracker

โครงการนี้เป็นโปรแกรมภาษา Python ที่พัฒนาขึ้นเพื่อช่วยแก้ปัญหาการติดตามรายรับ-รายจ่ายในชีวิตประจำวัน โดยโปรแกรมจะช่วยบันทึกข้อมูลการใช้จ่าย เก็บรักษาประวัติข้อมูลอย่างเป็นระบบ และคำนวณสรุปยอดการใช้จ่ายทั้งแบบรายสัปดาห์และรายเดือนผ่าน Discord ซึ่งเป็นแอปพลิเคชันที่ผู้คนจำนวนมากใช้งาน จึงเป็นที่มาของการพัฒนาโครงการนี้ขึ้นมา

## คลิปสอนตั้งค่า

[ดูวิดีโอสอนตั้งค่าบอท](https://www.youtube.com/watch?v=2k9x0s3awss&t=952s)

## วิธีใช้งาน

1. นำ Token ของ Discord Bot ไปใส่ในตัวแปร `DISCORD_TOKEN` ในไฟล์ `bot.py`
2. กำหนด `CHANNEL_ID` ให้เป็น ID ของช่อง Discord ที่ต้องการใช้งาน

## คำสั่งของบอท

- `!spend 50 Lunch | Food` — บันทึกรายจ่าย
- `!week` — สรุปรายจ่ายในช่วง 7 วันที่ผ่านมา
- `!month` — สรุปรายจ่ายของเดือนนี้
- `!categories` — สรุปรายจ่ายแยกตามหมวดหมู่
- `!recent 5` — แสดงรายการรายจ่ายล่าสุด 5 รายการ
